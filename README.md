# 💫 About Me

I'm a programmer focused on building games, interactive software, and web experiences. I primarily work with **JavaScript, Python, and C++**, while also exploring technologies such as **Rust** and a broad range of web and graphics tools.

I develop and maintain **[jenitzio.co.uk](https://jenitzio.co.uk)**, a personal web platform where I build and improve interactive projects, browser-based games, and useful online experiences. My goal is to make the site more engaging, practical, and enjoyable to use while continually improving its design, features, and performance.

My work spans front-end and back-end web development, game-related projects, server components, interactive graphics, and experiments with lower-level programming. I'm also developing a growing suite of **free creative tools** for workflows such as photography, image editing, video, and music, with an emphasis on making capable tools accessible through well-designed software.

I enjoy taking an idea from concept to implementation, experimenting with technologies, integrating projects, and refining the details that make software useful.
